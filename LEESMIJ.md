# Daily Dose Gallery — pakket voor Claude Code

In deze map zit alles om de website te laten bouwen.

- **BRIEF.md** — de bouwopdracht voor Claude Code (ontwerp, pagina's, vindbaarheid).
- **content/en.md** — alle teksten (de website is in het Engels).
- **content/works.json** — de schilderijen met titel, formaat en afbeelding.
- **images/** — de schilderijen, het portret van Julián en de foto's van de ruimte.

## Zo begin je

1. Pak dit bestand uit in een map op je computer, bijvoorbeeld "daily-dose-gallery".
2. Open de Claude-desktopapp, ga naar het tabblad Code en kies deze map.
3. Typ: "Lees BRIEF.md en bouw de website volgens de opdracht. Gebruik de teksten in content/en.md en de afbeeldingen in images/."
4. Kijk mee en vraag aanpassingen, net zoals je in de chat deed.
5. Claude Code richt ook het beheerscherm (CMS) in met Sanity. Daar zet je later zelf nieuwe schilderijen en kunstenaars op, en markeer je werken als verkocht. Je krijgt er een Nederlandse handleiding bij.
6. Laat Claude Code de site daarna online zetten op Netlify of Vercel en koppelen aan dailydosegallery.com. Voor Sanity en de hosting maak je zelf (gratis) een account aan; Claude Code vertelt je wanneer.

## Nog aanvullen

- Foto's van de ruimte in hoge resolutie (nu 600 × 400 pixels), liefst met de schilderijen aan de muur.
- Eventueel scherpere foto's van Baila 1 en Baila 2.
- Je Instagram-naam en de tekst voor de privacyverklaring.
- Een citaat van Julián, als je het blok "In their words" wilt gebruiken.
